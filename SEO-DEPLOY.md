# ADVANCED AUDIT — деплой и SEO

Статус на 24.09.2026: домен `advanced-audit.uz` живой, старый `best-audit-services.uz`
окончательно удалён (без редиректа — решение владельца). Сайт подтверждён в Google
Search Console, главная страница в индексе. Сайт теперь **многостраничный**: помимо
главной, есть 7 отдельных посадочных страниц под конкретные услуги.

## Деплой

```bash
npm install && npm run build
```

Собирать только через `npm run build` — он запускает `prerender.tsx`, который
генерирует статический HTML для **каждой** страницы (главная + 7 услуг + 404) и
пересобирает `sitemap.xml`. Голый `vite build` оставит сайт без текста для Google.

На сервере (`DEPLOY_DIR` — папка сайта на сервере, `site-build.zip` — архив со свежей сборкой):

```bash
cd "$DEPLOY_DIR" && rm -rf dist && unzip -o site-build.zip && pm2 restart <app-name>
```

`npm install` нужен только если менялись зависимости (сейчас добавлен
`react-router-dom` — если у вас старая нода_modules, накатите `npm install` один раз).

## Структура страниц

| URL | Целевой запрос |
|---|---|
| `/` | главная, бренд, обзор всех услуг |
| `/audit-tashkent` | «аудит Ташкент», «аудиторские услуги» |
| `/uslugi/obyazatelnyy-audit` | обязательный аудит финансовой отчётности |
| `/uslugi/nalogovyy-audit` | налоговый аудит |
| `/uslugi/initsiativnyy-audit` | инициативный аудит |
| `/uslugi/msfo-transformatsiya` | трансформация отчётности в МСФО |
| `/uslugi/buhgalterskie-uslugi` | бухгалтерские услуги / аутсорсинг |
| `/uslugi/nalogovyy-konsalting` | налоговый консалтинг |

Каждая страница — отдельный физический файл `dist/<путь>/index.html` со своим
`<title>`, `description`, `canonical` и разметкой `FAQPage` (вопросы могут
показываться прямо в выдаче Google). Все страницы перелинкованы: с главной —
через карточки услуг и подвал, с каждой страницы услуги — хлебные крошки на
главную и блок «Другие услуги» на соседние страницы.

Текст добавляется в `src/content/pages.ts` — один объект на страницу, вёрстка
общая (`src/components/ServicePage.tsx`).

## Sitemap

Обновляется автоматически при каждой сборке, ничего править вручную не нужно.
Сейчас в нём 8 адресов (главная + 7 страниц услуг), 404 в sitemap не входит —
так и должно быть.

## 404

Несуществующий адрес отдаёт настоящий HTTP 404 с оформленной страницей
(`dist/404.html`), а не копию главной. Проверено:

```bash
curl -s -D - -o /dev/null https://advanced-audit.uz/несуществующий-путь
```

Должно быть `HTTP/1.1 404`.

## Google Search Console

- Ресурс `https://advanced-audit.uz` подтверждён, тег в `index.html`.
- Sitemap отправлен через **Файлы Sitemap** → значение `sitemap.xml` (не `/`).
- После каждого добавления новой страницы — «Проверка URL» → «Запросить
  индексирование» для неё отдельно, sitemap подхватит её сам, но не сразу.
