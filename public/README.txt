Здесь лежат статические файлы сайта (доступны по прямой ссылке, например /logo.png).

1. Фотографии команды:
   - в публичном репозитории реальные фото сотрудников не хранятся;
   - по умолчанию используется заглушка team/placeholder.svg;
   - чтобы показать настоящие фото, положите файлы в public/team/
     и укажите пути в src/components/Team.tsx.

2. Видео:
   - video/hero-bg.mp4 (фон главного экрана)
   - video/cta-bg.mp4 (фон финального блока, тёмная тема)
